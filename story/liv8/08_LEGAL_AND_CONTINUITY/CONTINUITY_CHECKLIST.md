# Continuity Checklist

Before approving every generated shot:
- [ ] Facial identity matches canonical reference
- [ ] Hairline and facial hair consistent
- [ ] Skin tone consistent
- [ ] Correct character mode / wardrobe
- [ ] Era-specific lighting language maintained
- [ ] No random tattoos/accessories
- [ ] Hands/anatomy stable
- [ ] No fake readable accusations/logos
- [ ] No invented legal documents
- [ ] No location or person unintentionally identifiable
- [ ] Center-safe for 9:16 crop
- [ ] Scene has symbolic or narrative purpose
- [ ] Nothing is present merely because it “looks futuristic”

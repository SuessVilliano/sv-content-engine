# Base Character Consistency Prompt

Use the supplied Jamaur reference image as the facial-identity anchor.

Create a stylized cinematic-realism version of the same man, early-40s appearance,
lean build, close-cropped black hair, defined eyebrows, narrow mustache/goatee,
warm brown skin, expressive eyes, confident but thoughtful presence.

Visual language: premium adult animated drama, graphic-novel realism, volumetric
cinematic lighting, subtle painterly surface texture, realistic anatomy and hands,
natural skin detail, dimensional 3D environments, emotionally credible facial acting.

Do not turn him into a superhero, comic caricature, generic stock model, or glossy
corporate avatar. Preserve facial proportions and identity across all shots.

Camera behavior and wardrobe should change by era, but facial identity must remain stable.
